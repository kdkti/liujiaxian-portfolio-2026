# 淘宝公开数据分析说明

## 数据来源

- 原始数据集：阿里巴巴天池 User Behavior Data from Taobao for Recommendation
- 官方页面：https://tianchi.aliyun.com/dataset/649
- 公开镜像：https://www.kaggle.com/datasets/marwa80/userbehavior
- 许可：CC BY-NC-SA 4.0
- 分析日期：2026-10-31

本分析是个人独立完成的公开数据分析，不代表淘宝、阿里巴巴或任何公司的内部项目、客户资料和真实经营收益。

## 文件说明

- `taobao_analysis_summary.json`：全量扫描后的清洗结果、覆盖范围、漏斗、留存、RF 分层和头部分布。
- `taobao_public_sample_50k.csv`：从有效记录中按五字段确定性哈希、模数 2000 抽取的 50,209 行核验样本。
- `daily_metrics.csv`：9 个自然日的互动量、活跃用户、购买用户与购买率。
- `behavior_funnel.csv`：用户层行为覆盖漏斗。
- `retention_cohorts.csv`：按首次活跃日计算次日留存。
- `rf_buyer_segments.csv`：购买用户按最近购买日和购买频次交叉分层。
- `daily_metrics.csv`、`hourly_activity.csv`：日期与小时分布。
- `top_categories.csv`、`top_buy_items.csv`：类目和购买商品集中度。
- `taobao_public_analysis.py`：全量重算脚本。

原始 CSV 约 3.67 GB，不随作品集分发。按脚本和上述来源可重新下载并复现。

## 清洗口径

- 原始记录：100,150,807 条。
- 有效记录：100,095,231 条。
- 时区：UTC+08:00。
- 有效窗口：2017-11-25 00:00:00 至 2017-12-03 23:59:59。
- 剔除窗口外异常时间戳：55,576 条。
- 非法行为类型：0 条。
- 缺失字段：0 个。
- 分块内精确重复：49 条，作为质量项单独披露。
- 清洗后覆盖：987,991 个用户、4,161,138 个商品、9,437 个类目。

## 指标边界

- 用户层漏斗按“是否在观察窗口内发生某类行为”计算，不代表严格的单次会话路径。
- 事件层购买占比是购买事件数除以全部有效行为事件数。
- 数据没有价格、成本和利润字段，因此只计算 RF，不计算金额 M、GMV 或客单价。
- 7 日留存只纳入 11 月 25 日和 26 日首次活跃的用户，受固定 9 日观察窗口限制。
- 类目和商品 ID 已脱敏，本报告不推断具体行业、商品名称或真实销售结果。
- 时间分布和分组差异属于观察结果，不构成因果结论。
